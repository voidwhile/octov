# Octov HM

`hm` 目录现在承载 Octov 的 HarmonyOS 6.0 版本实现，目标是对齐 `dev` 分支的媒体库、阿里云盘、TMDB、字幕、播放历史和设置能力，并以 ArkTS / ArkUI 重新组织界面。

## 当前迁移状态

- 已建立 HarmonyOS 6.0 Stage 工程骨架
- 已迁入核心模型、TMDB / 字幕 / 阿里云盘 / 扫描服务的 ArkTS 版本
- 已搭建鸿蒙风格的双栏媒体库主界面、详情页、媒体源页、设置页、音乐页
- 已加入平台适配层骨架：本地目录选择、播放控制、仓库状态保存都已抽象，可直接替换为真机实现
- 已保留继续接通播放器、本地文件选择器、偏好持久化的扩展点

## 后续建议

1. 在 DevEco Studio 中打开 `hm`，补齐签名和图标资源。
2. 接入 HarmonyOS 文件选择器和 AVPlayer，完成本地媒体浏览与播放。
3. 用 Preferences / Database 持久化设置、媒体缓存和历史记录。
4. 补充真机联调，重点验证 HarmonyOS 6.0 上的网络权限与云盘播放链路。
